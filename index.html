Guida Pratica

Come aggiungere nuove simulazioni

L'architettura del repository è studiata per permetterti di espandere la raccolta in qualsiasi momento.

1

Salva il file HTML

Salva il nuovo file generato da Gemini nella cartella del progetto (ad esempio: nuova_simulazione.html).

2

Aggiungi la Card

In questo file index.html, duplica uno dei blocchi <article> inserendo il titolo e il link al nuovo file.

3

Push su GitHub

Esegui il commit e push del progetto: GitHub Pages aggiornerà automaticamente il sito online in 60 secondi!

Snippet per nuova card (da copiare in index.html) HTML 
<!-- Esempio nuova card -->
<article class="sim-card neon-card rounded-3xl overflow-hidden flex flex-col" data-category="fisica">
    <div class="p-6 flex flex-col flex-grow justify-between">
        <h3 class="text-xl font-bold text-white mb-2">Titolo Simulazione</h3>
        <p class="text-sm text-slate-300 mb-6">Descrizione della nuova simulazione.</p>
        <a href="nome_file_creato_da_gemini.html" class="glow-button px-6 py-3 rounded-2xl bg-cyan-600 text-white font-semibold text-center">
            Avvia Simulazione
        </a>
    </div>
</article>
